# เครื่องคำนวณภาษีเงินได้บุคคลธรรมดาไทย

เว็บไซต์ภาษาไทยสำหรับพนักงานประจำเพื่อประมาณภาษีเงินได้บุคคลธรรมดา อธิบายลำดับคำนวณ และแสดงผลกระทบของรายการลดหย่อน โดยไม่ส่งข้อมูลออกจากอุปกรณ์

## โครงสร้างโปรเจกต์

```text
.
├── index.html            # โครงหน้าและฟอร์มภาษาไทย
├── styles.css            # รูปแบบ responsive และ accessibility
├── tax-config.js         # ปีภาษี อัตราภาษี และกฎ/เพดานที่ปรับแก้ได้
├── calculator.js         # ฟังก์ชันคำนวณที่แยกจาก UI
├── app.js                # เชื่อมฟอร์มกับผลคำนวณ
├── server.js              # เซิร์ฟเวอร์ไฟล์ local สำหรับทดลองใช้งาน
└── calculator.test.js    # Unit tests ด้วย node:test
```

## ติดตั้งและเปิดใช้งาน

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

```bash
npm test
npm run start
```

จากนั้นเปิด http://localhost:8080 ในเบราว์เซอร์

`npm run start` เปิดเซิร์ฟเวอร์ไฟล์แบบ local สำหรับให้เบราว์เซอร์โหลดหน้าเว็บและโมดูล JavaScript; ไม่มี API และไม่มีการส่งข้อมูลฟอร์มออกไป

## สูตรและลำดับการคำนวณ

1. รายได้รวม = เงินเดือนต่อเดือน × จำนวนเดือน + โบนัส + ค่าคอมมิชชัน + ค่าล่วงเวลา + รายได้อื่น
2. ค่าใช้จ่ายจากการจ้างงาน = ค่าต่ำกว่าระหว่าง 50% ของเงินเดือน โบนัส ค่าคอมมิชชัน และค่าล่วงเวลารวมกัน กับเพดานใน `tax-config.js`
3. ค่าลดหย่อนที่ใช้จริง = จำนวนที่แจ้ง หักตามเพดานรายรายการและเพดานรวมที่กำหนดใน configuration
4. เงินได้สุทธิ = ค่าสูงกว่าระหว่าง 0 และ (รายได้รวม − ค่าใช้จ่าย − ค่าลดหย่อน)
5. ภาษีคำนวณแยกตามช่วงเงินได้สุทธิ: ภาษีช่วง = เงินได้ที่อยู่ในช่วง × อัตราของช่วง
6. ยอดสุทธิ = ภาษีคำนวณได้ − ภาษีหัก ณ ที่จ่าย (ค่าบวกคือจ่ายเพิ่ม ค่าลบคือประมาณการเงินคืน)

## ชุดข้อมูลตัวอย่างและผลที่คาดหวัง

ข้อมูลตามโจทย์: เงินเดือน 40,000 บาท × 12 เดือน, โบนัส 50,000 บาท, ภาษีหัก ณ ที่จ่าย 15,000 บาท, ประกันสังคม 9,000 บาท และไม่มีรายการอื่น

| ขั้น | ผล |
|---|---:|
| รายได้รวม | 530,000 บาท |
| ค่าใช้จ่ายเงินเดือน (50% แต่ไม่เกิน 100,000 บาท) | 100,000 บาท |
| ค่าลดหย่อนส่วนตัว | 60,000 บาท |
| ประกันสังคมตามข้อมูลที่กรอก | 9,000 บาท |
| ค่าลดหย่อนรวม | 69,000 บาท |
| เงินได้สุทธิ | 361,000 บาท |
| ภาษี 150,001–300,000 (150,000 × 5%) | 7,500 บาท |
| ภาษี 300,001–500,000 (61,000 × 10%) | 6,100 บาท |
| ภาษีก่อนหัก ณ ที่จ่าย | 13,600 บาท |
| ประมาณการภาษีคืน (15,000 − 13,600) | 1,400 บาท |

ผลตัวอย่างนี้ตั้งอยู่บนค่าเริ่มต้นใน configuration ไม่ใช่การยืนยันสิทธิทางภาษี

## การทดสอบ

`npm test` ทดสอบภาษีที่เงินได้สุทธิ 0, 150,000, 300,000, 500,000, 1,000,000, 2,000,000, 5,000,000 บาท และกรณีมากกว่า 5,000,000 บาท รวมถึงค่าก่อน/หลังจุดเปลี่ยน 1 บาท และเงื่อนไขอัตราภาษีเฉลี่ยไม่เกินอัตราขั้นสูงสุด

## กฎภาษีและเพดานที่ต้องยืนยันก่อนนำขึ้นใช้งานจริง

- `tax-config.js` เป็นจุดเดียวสำหรับแก้ปีภาษี อัตราภาษี ค่าใช้จ่าย และเพดานรายการลดหย่อน
- ปีภาษีตั้งต้นคือ 2569; อัตราภาษีขั้นบันไดเป็นข้อมูลตั้งต้นตามโจทย์ ไม่ได้ยืนยันความเปลี่ยนแปลงของกฎหมายปี 2569
- รายการที่มีจำนวนตั้งต้นใน configuration แสดงป้าย **ต้องตรวจสอบกับกรมสรรพากร** เพราะยังไม่ได้ตรวจยืนยันกับประกาศทางการสำหรับปีภาษีนี้
- เพดานที่ซับซ้อนหรือไม่ยืนยัน (เช่น กองทุนเพื่อการออมที่ยังมีสิทธิ, มาตรการเฉพาะปี, รายการอื่น) จะไม่สร้างตัวเลขขึ้นเอง ระบบแสดงสถานะว่าต้องตรวจสอบ และจำนวนที่กรอกจะถูกนับเป็นค่าประมาณโดยไม่จำกัดเพดานที่ยังไม่ทราบ
- สิทธิบุตรขึ้นกับปีเกิดและเงื่อนไขอื่นที่อาจเปลี่ยนได้ ต้องยืนยันเกณฑ์/เพดานของปีภาษี
- การหักเงินบริจาคมีเพดานที่ขึ้นกับเงินได้หลังรายการอื่น ระบบจึงแสดงข้อจำกัดการคำนวณและควรตรวจสอบจำนวนที่ใช้ได้กับกรมสรรพากร
- ประกันสังคมใช้จำนวนเงินสมทบจริงที่ผู้ใช้กรอก ไม่มีการอนุมานสิทธิจากเงินเดือน
- ตรวจสอบกฎ เพดาน เงื่อนไขการใช้สิทธิ และลำดับหักตามแบบ/คำแนะนำของกรมสรรพากร ก่อนยื่นแบบหรือเผยแพร่ใช้งานจริง

## ความเป็นส่วนตัวและข้อจำกัด

ข้อมูลฟอร์มคำนวณในหน่วยความจำของเบราว์เซอร์เท่านั้น ไม่มีการส่งหรือบันทึกรายได้บนเซิร์ฟเวอร์ เว็บไซต์นี้เป็นเครื่องมือประมาณการ ไม่ใช่คำแนะนำหรือผลวินิจฉัยภาษีอย่างเป็นทางการ
